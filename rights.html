حقوق المشروع وسياسة الاستخدام

UON Hub مشروع طلابي مستقل وغير تابع رسميًا لجامعة نزوى. تصميم الواجهات، النصوص الأصلية، الشفرة البرمجية والهوية الخاصة بالمشروع محمية، ولا يجوز نسخها أو إعادة نشرها على أنها عمل مستقل دون إذن.

المسموح

  • مشاركة رابط الموقع الرسمي والاستفادة من خدماته.
  • الاقتباس المحدود مع ذكر UON Hub بوضوح ووضع رابط للمصدر.
  • طلب تعاون أو إذن كتابي لإعادة استخدام جزء محدد.

غير المسموح

  • نسخ الواجهة أو الملفات أو النصوص ونشرها باسم مشروع آخر.
  • إزالة إشعارات الحقوق أو البصمات الرقمية أو بيانات المصدر.
  • استخدام اسم UON Hub أو هويته بطريقة توحي بالشراكة أو التبعية الرسمية.

تنبيه للنسخ غير المصرح

تتضمن ملفات المشروع معرّفات وبصمات رقمية غير مؤذية لإثبات المصدر. عند اكتشاف نسخ واضح، يتم توثيق الرابط والتاريخ والأدلة ثم التواصل مع صاحب الموقع أو مزود الاستضافة بطلب إزالة رسمي. لا يستخدم المشروع أي أسلوب تخريبي أو وصول غير مصرح به.
